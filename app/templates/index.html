连接中… REST API 文档

外部地址输入

每行一条地址；或直接粘贴一条。系统会自动统一 Unicode、大小写、道路缩写与门牌号格式。

外部地址映射批次

上传含 业务编号 与 原始地址 的 CSV（最多 100 行），服务端在 同一标准地址表快照下按现有匹配规则（默认阈值，纯评分）逐行生成映射并保存批次； 批次运行不查询复核共识、不写普通匹配日志。 业务编号相同但地址不同的行标记为编号冲突，系统不会任选一行； 回看批次可查看每行原文、匹配状态、候选与冲突原因。下载完整映射 CSV 时会 重新核对当前地址表摘要：快照变化则拒绝导出，需重新建批次； 未自动命中或编号冲突的行保留原编号、目标 ID 留空并写明原因。

CSV 必须含表头：业务编号列可识别 biz_no、business_id、 ref、业务编号 等；地址列可识别 address、 raw_address、原始地址 等（无地址列时也可用 line1/street 等结构化列拼接）。

历史批次

点击批次编号回看每行原文、匹配状态、候选与冲突原因；「下载映射」前服务端会重新核对地址表快照。

规则 A/B 对照实验

提交 2~4 个命名规则档案（自动命中 / 拒绝 / 分差阈值与词元权重）和 1~100 条查询， 服务端在同一标准地址表快照下逐档运行现有匹配器。档案参数非法或查询重复时逐项报错且不执行； 结果持久化，可按实验编号回看。

实验查询

历史实验

点击编号回看完整结果；「→基准 / →对比」可直接填入下方回归对比

历史回归对比

选择两次已持久化的实验，服务端按档案名称与去首尾空白后的查询逐档对齐， 比较状态 / 首选地址 / 得分变化并分类为 改善 / 退化 / 仅分数变化 / 无变化。 档案缺失或查询重复的实验会被拒绝对比；地址表快照 digest 不同时提示不可直接比较，但仍展示逐条差异。

标准地址表

CSV 支持的列名：address(或 full_address)、line1(street)、 city(town)、state(province)、 postal_code(zip/postcode)、country、 external_id(或 id)。 预览模式下先展示有效/重复/无效数量及无效行号，可点击「影响预演」用本次有效行 对最近 100 条不同查询做内存干跑（不写入），确认后仅写入有效记录； 取消勾选则沿用直接上传接口 /api/addresses/upload。

待确认队列

单条复核实行领取制：填写复核员姓名后点击记录上的「领取」， 获得 10 分钟租约与复核令牌；同一时刻一条记录只允许一个有效令牌， 过期后可重新领取。提交复核须持有有效令牌（过期、旧令牌或重复提交会被拒绝）， 也可随时「释放」让出记录。同案整组复核遇到仍被领取的成员会整体拒绝。

复核结论回放

取全部已复核记录，以原查询在当前标准地址表上按默认规则重新匹配 （纯评分，不查询复核共识记忆），逐条对照人工结论： 确认 / 改派记录自动命中所选地址为一致，自动命中其他地址为冲突， 未自动命中为漏命中；判无匹配记录出现自动命中为误命中，否则为一致。 人工所选地址的 ID 与全文在复核写入时已持久保存，地址删除后仍可显示原 ID、全文与复核得分， 并按当前地址表标注其是否已删除；历史记录若已失去可确定的所选 ID，则标记为原选择未知， 不从候选列表猜测。用于定位规则或地址表变化带来的风险；本页只读，不写入匹配日志，也不改动复核记录。

地址覆盖缺口

清单来自已保存且状态为无匹配的匹配日志，按归一化后的 道路词元 + 地区词元 + 门牌号归组（门牌号不同不算同一缺口）。 每次打开或刷新都会用当前标准地址表与默认规则重跑每组代表查询： 现已能自动命中的组标记为已覆盖（显示命中地址）， 其余仍为待补录（显示当前首选候选）。此页面不写入或改写任何日志。

标准地址自匹配巡检

对当前标准地址表中的每一条记录，以其全文作为查询、按默认规则在 完整地址表上重新评分，只列出未能自动命中自身 ID 的记录。 每条风险给出自身分数，以及所有得分不低于 自身分数 − 默认分差阈值 的其他地址（阻碍候选，不受前五候选截断）。 判定分三类：自身分数低于自动命中阈值为自身分数不足；自身达标但首选不是自身为 首选偏移；首选是自身但领先次高分不足为分差歧义。 上传新表后点击「重新巡检」即按最新表重新计算；本页只读，不生成匹配日志。
